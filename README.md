🚀 Installation et Démarrage Local
Prérequis
Node.js version 16 ou supérieure

npm ou yarn

Instructions d'installation
bash
# 1. Cloner le dépôt
git clone https://github.com/votre-username/mamzy-color-kids.git

# 2. Se déplacer dans le dossier
cd mamzy-color-kids

# 3. Installer les dépendances
npm install

# 4. Démarrer le serveur de développement
npm run dev

# 5. Ouvrir dans le navigateur
# Le site sera accessible à: http://localhost:5173
Commandes Disponibles
bash
# Serveur de développement
npm run dev

# Build de production
npm run build

# Preview du build
npm run preview

# Linting
npm run lint

🌐 Déploiement
Déploiement Automatique avec Netlify
Le site est configuré pour le déploiement continu :

Connectez votre dépôt GitHub à Netlify

Configurez les paramètres de build :

Build Command: npm run build

Publish Directory: dist

Ajoutez les variables d'environnement pour EmailJS

Variables d'Environnement
env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
